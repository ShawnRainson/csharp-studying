1. Что такое C#?

C# (C Sharp) — это язык программирования.

На нём можно создавать:

веб-приложения;
серверы и API;
desktop-программы;
игры;
мобильные приложения;
различные сервисы и инструменты.

Но здесь важно не путать две вещи:

C#     → язык программирования
.NET   → платформа, на которой работают приложения

Например:

C# код
   ↓
компилятор
   ↓
.NET
   ↓
программа

Официальная документация Microsoft рассматривает C# и .NET именно как связанные, но разные вещи: C# — язык, а .NET предоставляет платформу и библиотеки для создания приложений.

2. Что такое .NET SDK?

Мы говорили, что тебе нужно установить .NET SDK.

SDK — это набор инструментов для разработки.

Он позволяет нам:

создавать проекты;
компилировать C#;
запускать программы;
работать с .NET;
использовать команду dotnet.

На официальной странице Microsoft сейчас рекомендуется .NET 10 LTS; SDK включает инструменты, необходимые для создания и запуска .NET-приложений, а также поддержку C#.

Поэтому пока запомни:

C#      → язык
.NET    → платформа
.NET SDK → инструменты разработчика
3. Наша первая программа

Самая простая программа:

Console.WriteLine("Hello, World!");

Она выводит:

Hello, World!

Разберём:

Console

Это объект/тип, связанный с консолью.

WriteLine

Метод, который выводит строку в консоль.

"Hello, World!"

Текст, который мы хотим вывести.

Поэтому:

Console.WriteLine("Hello, World!");

можно пока читать примерно так:

«Выведи этот текст в консоль».

Это соответствует официальному примеру Microsoft для первой C#-программы.

4. Что такое переменная?

Теперь самое главное на сегодня.

Представь коробку:

┌───────────────┐
│      25       │
└───────────────┘
      age

У коробки есть:

имя    → age
значение → 25

В программировании такая «коробка» называется переменной.

Например:

int age = 25;

Здесь:

int  → тип данных
age  → имя переменной
25   → значение
=    → присваивание

То есть:

int age = 25;

означает:

Создай переменную age типа int и положи в неё значение 25.

В C# каждая переменная имеет тип, который определяет, какие значения она может хранить. C# является строго типизированным языком.

5. int — целые числа

int используется для целых чисел.

Например:

int age = 25;
int year = 2026;
int score = 100;
int temperature = -5;

Можно представить:

age
 ↓
25

year
 ↓
2026

А потом изменить значение:

int age = 25;

age = 26;

Теперь:

age → 26

Тип переменной при этом не изменился.

Она всё ещё:

int
6. double — числа с дробной частью

Если нам нужно хранить дробные числа:

double price = 19.99;
double temperature = 36.6;
double height = 1.82;

Например:

double price = 19.99;

Console.WriteLine(price);

Получим:

19.99
7. string — текст

Для текста используется:

string

Например:

string name = "Alex";
string city = "Prague";
string message = "Hello!";

Обрати внимание:

string name = "Alex";

Alex находится в кавычках:

"Alex"

Потому что это текст.

8. bool — да или нет

bool может иметь только два значения:

true
false

Например:

bool isOnline = true;
bool isAdmin = false;
bool isAdult = true;

Можно представить:

isOnline
   ↓
 true

или:

isOnline
   ↓
 false

Это понадобится нам буквально через несколько занятий, когда мы начнём изучать условия.

9. Как вывести переменные?

Можно передать переменную в Console.WriteLine():

string name = "Alex";
int age = 25;

Console.WriteLine(name);
Console.WriteLine(age);

Получим:

Alex
25

Можно вывести несколько значений через интерполяцию строк:

string name = "Alex";
int age = 25;

Console.WriteLine($"Name: {name}");
Console.WriteLine($"Age: {age}");

Получим:

Name: Alex
Age: 25

Здесь:

$"Name: {name}"

означает:

Вставь значение переменной name внутрь текста.

Это называется интерполяцией строк.

Пока просто запомни синтаксис:

$"текст {переменная}"
10. Почему нельзя положить строку в int?

Посмотри:

int age = "25";

Так делать нельзя.

Почему?

Потому что:

int

ожидает целое число:

25

а мы передали:

"25"

Это уже строка.

Для компьютера это разные типы:

25

и

"25"

Первое:

int

Второе:

string

Поэтому компилятор сообщит об ошибке ещё до запуска программы. Это одна из важных особенностей строгой типизации C#.

11. Переменную можно изменить

Например:

int age = 25;

age = 26;

После последней строки:

age → 27

Но вот так нельзя:

int age = 25;

age = "Alex";

Потому что age была объявлена как:

int

а "Alex" — это:

string
12. Важный нюанс — var

В C# существует ещё:

var

Например:

var age = 25;
var name = "Alex";
var price = 19.99;

Компилятор сам определяет тип:

var age = 25;
      ↓
    int

var name = "Alex";
       ↓
    string

var price = 19.99;
        ↓
    double

Но var не означает, что переменная становится без типа.

Например:

var age = 25;

age всё равно имеет тип:

int

Мы подробнее разберём var позже. Пока в обучении я хочу, чтобы ты чаще видел явный тип:

int age = 25;
string name = "Alex";

Так проще понять фундамент.

1. Арифметические операторы
Начнём с самого простого.
В C# есть обычные математические операции:
int a = 10;
int b = 3;

Сложение +
Console.WriteLine(a + b);

Получим:
13

Вычитание -
Console.WriteLine(a - b);

Получим:
7

Умножение *
Console.WriteLine(a * b);

Получим:
30

Обрати внимание:
В программировании умножение обозначается:
*

а не:
×

Деление /
Console.WriteLine(a / b);

И вот здесь появляется важный нюанс.
Мы ожидаем:
3.333333...

но получим:
3

Почему?
Потому что:
a

и
b

имеют тип:
int

А при делении двух int результатом является целочисленное деление.
То есть дробная часть отбрасывается.
10 / 3
 ↓
3

2. А что если использовать double?
Смотрим:
double a = 10;
double b = 3;

Console.WriteLine(a / b);

Теперь результат будет примерно:
3.3333333333333335

Потому что здесь используется дробный тип:
double

Получается:
int / int
↓
целочисленный результат

а:
double / double
↓
дробный результат

Это очень важный момент, который тебе понадобится дальше.
3. Остаток от деления — %
Теперь интересный оператор:
%

Он возвращает остаток от деления.
Например:
Console.WriteLine(10 % 3);

Получим:
1

Почему?
Потому что:
10 / 3 = 3

и остаётся:
1

Можно представить:
10 = 3 × 3 + 1

Поэтому:
10 % 3 → 1

Другие примеры:
Console.WriteLine(10 % 2);
Console.WriteLine(15 % 4);
Console.WriteLine(20 % 5);

Результат:
0
3
0

4. Зачем вообще нужен %?
Очень часто нужно проверить, является ли число чётным.
Например:
10 % 2

даёт:
0

А:
11 % 2

даёт:
1

Поэтому позже мы сможем написать:
if (number % 2 == 0)
{
    // число чётное
}

Пока if мы ещё не изучали, поэтому просто запомни сам принцип:
number % 2 == 0
        ↓
    число чётное

К этому вернёмся, когда начнём условия.
5. Оператор присваивания =
Мы уже встречались с ним:
int age = 25;

Очень важно не путать:
=

с математическим знаком «равно».
В программировании = означает:
присвоить значение переменной.

Например:
int age = 25;

Здесь мы говорим:
age ← 25

А:
age = 30;

означает:
age ← 30

6. +=
На прошлом занятии ты самостоятельно использовал:
newAge += 1;

Теперь разберём его официально.
Если есть:
int age = 20;

то:
age += 5;

эквивалентно:
age = age + 5;

После этого:
age → 25

7. Остальные составные операторы
Точно так же работают:
-=
int age = 20;

age -= 5;

Это то же самое, что:
age = age - 5;

Результат:
15

*=
int number = 10;

number *= 3;

То же самое:
number = number * 3;

Результат:
30

/=
int number = 20;

number /= 4;

То же самое:
number = number / 4;

Результат:
5

🧠 Главная таблица дня
Оператор	Что делает	Пример	Результат
+	сложение	10 + 3	13
-	вычитание	10 - 3	7
*	умножение	10 * 3	30
/	деление	10 / 3	3 при int
%	остаток	10 % 3	1

-=	вычесть	x -= 5	x = x - 5

8. Порядок выполнения операций
C# соблюдает обычный математический порядок операций.
Например:
int result = 2 + 3 * 4;

Сначала:
3 * 4

Получаем:
12

Затем:
2 + 12

И результат:
14

Не:
20

Скобки меняют порядок
Например:
int result = (2 + 3) * 4;

Сначала:
2 + 3 = 5

Затем:
5 * 4 = 20

Получаем:
20

Поэтому скобки:
()

позволяют явно указать, что нужно выполнить первым.
9. Важный нюанс: тип результата
Посмотри:
int a = 10;
int b = 3;

int result = a / b;

Получим:
3

Но если:
double a = 10;
double b = 3;

double result = a / b;

получим:
3.333333...

Поэтому тип данных влияет на результат операции.
Это одна из причин, почему мы так подробно изучаем типы данных.

1. Теория: зачем нужны сравнения?
До этого мы учили компьютер выполнять вычисления. Но программа должна не только считать — она должна ещё и принимать решения.
Например:
- Если возраст пользователя не меньше 18 лет — разрешить доступ.
- Если денег достаточно — разрешить покупку.
- Если число равно нулю — сообщить об этом.
- Если температура выше заданного значения — вывести предупреждение.
Для этого сравнивают значения.
2. Операторы сравнения
Оператор	Значение	Пример	Результат
==	Равно	5 == 5	true
!=	Не равно	5 != 3	true
>	Больше	8 > 4	true
<	Меньше	2 < 7	true
>=	Больше или равно	5 >= 5	true
<=	Меньше или равно	3 <= 2	false
Результат сравнения — логическое значение типа bool: либо true, либо false.
Пример:
int age = 20;

Console.WriteLine(age > 18);
Console.WriteLine(age == 20);
Console.WriteLine(age < 18);


Результат:
True
True
False


Почему? Потому что 20 больше 18, 20 равно 20, но 20 не меньше 18.
Важная разница: = и ==
int age = 20;


Здесь = присваивает переменной значение 20.
bool isTwenty = age == 20;


Здесь == сравнивает значение age с числом 20. Результат сохраняется в переменную isTwenty.
Вторая строка означает: «Переменная isTwenty хранит ответ на вопрос, равен ли возраст двадцати».
3. Условие if
if переводится как «если». Он позволяет выполнить код, только когда условие истинно.
int age = 20;

if (age >= 18)
{
    Console.WriteLine("Доступ разрешён");
}


Разберём по частям:
- if — начинаем проверку.
- (age >= 18) — условие, которое должно быть истинным.
- { } — блок кода, который выполняется, если условие истинно.
- Console.WriteLine(...) — действие, которое программа выполняет в этом случае.
Поскольку age равен 20, условие истинно и программа выводит:
Доступ разрешён


А если age будет равен 16? Условие станет ложным. Программа просто пропустит блок if.
4. Конструкция if / else
Что делать, если мы хотим обработать оба варианта?
Для этого есть else — «иначе».
int age = 16;

if (age >= 18)
{
    Console.WriteLine("Совершеннолетний");
}
else
{
    Console.WriteLine("Несовершеннолетний");
}


Результат:
Несовершеннолетний


Работает это так:
Проверяем условие
age >= 18

true
Выполняется if


false
Выполняется else




В одной конструкции if / else выполнится одна из двух веток, но не обе.
5. Несколько вариантов: else if
Допустим, нам нужно проверить оценку ученика:
- 90 и выше — отлично.
- 70 и выше — хорошо.
- 50 и выше — удовлетворительно.
- Ниже 50 — нужно повторить материал.
Для нескольких вариантов используется else if.
int score = 75;

if (score >= 90)
{
    Console.WriteLine("Отлично");
}
else if (score >= 70)
{
    Console.WriteLine("Хорошо");
}
else if (score >= 50)
{
    Console.WriteLine("Удовлетворительно");
}
else
{
    Console.WriteLine("Нужно повторить материал");
}


Результат:
Хорошо


Почему? Первая проверка score >= 90 ложна. Вторая проверка score >= 70 истинна, поэтому выводится Хорошо. До остальных веток программа уже не доходит.
Важный нюанс: порядок условий имеет значение. Проверки выполняются сверху вниз, и срабатывает первая подходящая ветка.
6. Практический пример: проверка баланса
int balance = 100;
int price = 75;

if (balance >= price)
{
    Console.WriteLine("Покупка разрешена");
}
else
{
    Console.WriteLine("Недостаточно средств");
}


Здесь мы сравниваем две переменные, а не конкретные числа. Это полезная привычка: программа будет работать и при других значениях balance и price.
Если balance = 100, а price = 75, покупка разрешена. Если изменить price на 120, выполнится ветка else.

7. Важные нюансы
1. = — присваивание, == — сравнение.
2. >= включает само число. Например, 18 >= 18 — true.
3. > не включает само число. Например, 18 > 18 — false.
4. Условие в if должно давать результат типа bool.
5. В if / else выполняется одна из двух веток.
6. В цепочке if / else if / else проверка идёт сверху вниз.
7. Фигурные скобки { } обозначают блок кода. Используй их последовательно, чтобы программа была понятной и удобной для чтения.
