Вопрос 1. Что выведет программа?
for (int i = 1; i <= 5; i++)
{
    if (i == 3)
    {
        break;
    }

    Console.WriteLine(i);
} - 1, 2


Вопрос 2. Что выведет программа?
for (int i = 1; i <= 5; i++)
{
    if (i == 3)
    {
        continue;
    }

    Console.WriteLine(i);
} - 1, 2, 4, 5


Вопрос 3. Сколько раз выполнится Console.WriteLine?
for (int i = 1; i <= 4; i++)
{
    for (int j = 1; j <= 3; j++)
    {
        Console.WriteLine("Hello");
    }
} - 12 раз


Вопрос 4. Что произойдёт с внешним циклом, если внутри вложенного цикла сработает break? - Ничего, он продолжится

Вопрос 5. Какая опасность существует при использовании continue внутри while, если изменение счётчика находится после continue? - Бесконечный цикл
