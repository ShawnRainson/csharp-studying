Задание 1

Что выведет программа?

int age = 25;

Console.WriteLine(age);

Вопросы:

Что выведется? - 25
Какой тип у age? - int
Какое значение хранится в age? - 25

Задание 2

Что здесь хранится в каждой переменной?

string name = "Alex";
int age = 25;
double height = 1.82;
bool isStudent = true;

Ответь:

name      → Alex
age       → 25
height    → 1.82
isStudent → True

Задание 3

Что произойдёт?

int age = 25;

age = 30;

Console.WriteLine(age);

Что выведется и почему? - 30, так как значение переменной было изменено
