Вопрос 1. Сколько раз выполнится тело цикла?
int x = 10;

while (x < 5)
{
    Console.WriteLine(x);
    x++;
} - Ни разу


Вопрос 2. Что выведет программа?
int x = 10;

do
{
    Console.WriteLine(x);
    x++;
}
while (x < 5); - 10


Вопрос 3. Сколько раз выведется слово Hello?
int i = 1;

while (i <= 3)
{
    Console.WriteLine("Hello");
    i++;
} - 3 раза


Вопрос 4. Какой цикл лучше выбрать, если нужно сначала попросить пользователя ввести число, а затем повторять запрос, пока число не станет положительным? - do while

Вопрос 5. В чём главное отличие while от do while?
Ответ: while сначала проверяет условие, а потом выполняет тело цикла, а do while - сначала выполняет тело, а потом проверяет условие
